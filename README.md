## Разработка

### Требования
Для установки и запуска проекта, необходим [NodeJS](https://nodejs.org/) v8+.

### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
$ npm i
```

### Запуск Development сервера
Чтобы запустить сервер для разработки, выполните команду:
```sh
npm start
```

### Создание билда
Чтобы выполнить production сборку, выполните команду: 
```sh
npm run build
```

## Модули

# masks.py
Содержит следующие функции:

	1) get_mask_card_number (Принимает на вход номер карты возвращает маску номера.)
	2) get_mask_account (Принимает на вход номер счета возвращает маску номера.)

# processing.py
Содержит следующие функции:

	1) filter_by_state (Возвращает список словарей, у которых значение ключа 'state' совпадает с указанным.)
	2) sort_by_date (Возвращает новый список словарей, отсортированный по дате (ключ 'date').)

# widjet.py
Содержит следующие функции:

	1) mask_account_card (Принимает строку с типом и номером, возвращает строку с замаскированным номером.)
	2) get_date (Принимает строку с датой в формате 'YYYY-MM-DDTHH:MM:SS.microseconds' и возвращает строку с датой в формате 'ДД.MM.ГГГГ'.)

# generators.py
Содержит следующие функции-генераторы:

	1) filter_by_currency (Возвращает итератор, который поочерёдно выдаёт транзакции с заданной валютой.)
	2) transaction_descriptions (Генератор, который поочередно возвращает описания операций ('description') из списка транзакций.)
	3) ard_number_generator (Генератор, выдающий номера банковских карт в формате 'XXXX XXXX XXXX XXXX' от start до end включительно.)
